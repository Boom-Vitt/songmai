# Songmai Implementation Plan

> **For agentic workers:** Execute inline with superpowers:executing-plans. Review the completed branch once before publication.

**Goal:** Publish a tested, downloadable Thai handoff kit with practical examples.

**Architecture:** Markdown Skill/template/prompts carry context; one stdlib CLI verifies declared files. A small offline example proves baseline/check/solution behavior.

**Tech Stack:** Python 3.9+, Markdown, GitHub Actions.

**Spec:** ../specs/2026-10-07-songmai-design.md

## Global Constraints

- Python 3.9+ stdlib only; no API keys or provider automation.
- Thai instructions, MIT, copy-ready create/resume commands.
- Read-only checker; references are workspace-relative files.
- Evidence reports must distinguish scripted examples from live agent runs.

## Review Focus

- Thai/spaces/BOM/CRLF input works, arbitrary cwd works with explicit root.
- Malformed or duplicate reference sections never falsely pass.
- Path traversal, Windows absolute paths and escaping symlinks fail without reading target content.
- UTF-8/read failures are controlled, help/usage works.
- ZIP instructions reproduce baseline failure and solution success without altering originals.
